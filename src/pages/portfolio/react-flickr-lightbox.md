React Flickr Lightbox is a reusable React component that can be consumed as an NPM module. It generates a lightbox image gallery from a Flickr feed, with keyboard navigation and lazy loading baked in.

It pairs naturally with React Flickr Hero. Together they cover the two things a photography-led site usually needs: a header that breathes and a gallery that gets out of the way.
