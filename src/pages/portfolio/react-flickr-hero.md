React Flickr Hero is a reusable React component that can be consumed as an NPM module. It generates a hero image based on the Flickr information you provide, rotating through a set of queried images at random on each load.

It's the kind of small, sharp building block I like: one job, sensible defaults, and no configuration overhead. Hand it a Flickr query and it takes care of the rest, a clean way to give a site a living, photography-led header.
